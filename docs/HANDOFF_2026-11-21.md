## Second migration increment — 2026-11-21 (same draft branch)

- **SamjuniorsOS payload-binding pattern adapted into Nexus:** src/lib/agent/action-binding.ts + tests; pending permission prompts carry SHA-256 action fingerprints, and the owner UI returns matching hashes for approvals. Routes and agent tools for browser, mobile, desktop, terminal, extensions, and self-heal call exact-action verification. Security does not rely on an LLM-provided confirmation flag.
- **Sensitive grants are single-use:** src/lib/agent/permission-policy.ts removes the Unlimited Always option for self-install, mobile, workspace shell, desktop bridge, and code repair. Old persisted Always rows are interpreted as Ask at runtime. Normal app UI convenience remains configurable.
- **Agent-side bypasses constrained:** Device bridge dispatch checks capability lists. The agent's pair_windows function no longer returns pairing tokens to an LLM; it opens the private owner Devices UI. Self-heal rollback and terminal execution require action-bound approval.
- **Offline disaster recovery:** scripts/offline-backup.mjs (+ synthetic fixture tests) creates and verifies private checksummed snapshots of explicitly supplied SQLite DB paths while the server is stopped. Real database restore remains a separate unverified procedure; no automatic restore or hot backup.
- **AI Studio handoff:** docs/AI_STUDIO_BUILD_HANDOFF.md and docs/migrations/SAMJUNIORSOS_PORT_LEDGER.md. Keep Nexus as source of truth, with protected PR and separate Windows Electron acceptance.
- **CI tests now run on actual Node:** run #130 passed the security and recovery suites, TypeScript validation, ESLint and production build. Native Windows/Electron and Android device tests remain outstanding.
